Lost Harbor documentation

Lost Harbor is a typed multiplayer-style role-playing game in a worn-down space setting. Type commands to explore, work, fight and fly. The browser panels show the world and offer shortcuts for the same commands.

§1. Player guide

Start playing for controls, commands, saves and your first ship. The guide includes a full opening walkthrough. That walkthrough contains spoilers.

§2. Developer guide

Build and extend the game for local setup, architecture, content tools and isolated playtesting. The native server and browser worker run the same Rust engine.

§3. API documentation

Browse the public Rust APIs for all workspace crates. The reference includes public signatures, explanations and cross-crate search. It excludes private items and source-code pages.

§Which version is this?

This site follows validated changes on the source repository’s main branch. It describes the development game. The production game follows stable releases and can differ.
