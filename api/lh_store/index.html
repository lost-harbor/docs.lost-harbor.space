Crate lh_store 

Expand description

Persistence for Lost Harbor hosts.

The engine never touches storage. It hands the host Records that changed (Engine::take_dirty) and receives every stored record at boot. A Store is the host-side half of that contract (Strategy pattern): MemoryStore for tests, SqliteStore (feature sqlite) for the native server. The browser worker keeps records in IndexedDB instead.

Each record has a kind and a key. Together they form the id, such as character/Ash, and that id is unique in every backend.
