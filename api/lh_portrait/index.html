Crate lh_portrait 

Expand description

Bust portraits for Lost Harbor, drawn from one 64-bit seed.

Every character has a portrait. Only the seed is stored. The client and the engine both call render_svg with the seed and get the same flat vector picture: hard-edged polygons in two tones, lit from one side, in the spirit of the 1991 game Another World.

Nothing is picked from a set of finished pictures. Each call builds the picture from scratch: the seed picks the parts, moves the base colours a little and sets the proportions, and the drawing code turns those choices into polygons. Repeats are possible, because the choices are finite, but they are rare.

People use five families. Machines, beasts and aliens each have their own generator in machine, beast and alien, with their own parts and their own edge and backdrop style, so they read apart from people.

The crate is pure. It reads no clock and does no I/O, so it builds for wasm32-unknown-unknown and gives the same picture on every machine.

§Seed layout

BitsMeaning
63 to 60The drawing version. See VERSION.
59 to 56The Family: the style pool the parts come from.
55 to 52For machines, beasts and aliens: a form forced by an author, such as beast:rat. 1 picks the first form. Any other value lets the random bits pick.
55 to 0Random bits. They pick every part and colour.

The version marks the drawing code a seed was made for. While the game is in alpha the drawing code changes in place, so a saved seed may change face: people gained poses and more parts this way. Once saved faces must stay put, a change adds a new version and keeps the old one.

§Design patterns

  • Flyweight: a face is one u64. The parts tables are shared and never copied.
  • Builder: face::Face decodes the seed into parts, then draw turns the parts into markup in a fixed order of layers.
