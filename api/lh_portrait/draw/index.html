Module draw 

Expand description

Turning a decoded Face into SVG markup.

The picture is built in layers, back to front: the backdrop, anything behind the head, the body, the neck, the head, the features, the face marks, the hair and the headgear. Each surface gets a lit tone and a shade tone. The light always falls from the left while drawing. A face lit from the right is mirrored by the drawing pen as each point is written.

The head is drawn facing front. A Pose then bends the points of the head layers as the pen writes them through a pose transform, so every part, old or new, follows the pose with no drawing of its own. The backdrop, the body, the neck and the collar are never bent, so the shoulders stay square and only the head moves.

The markup uses no element ids, so any number of portraits can share one page without clashes.
