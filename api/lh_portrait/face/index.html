Module face 

Expand description

Decoding a seed into the parts of a face.

Face::decode reads the random bits of a seed in a fixed order and picks each part from a table weighted by the Family. The order of the reads decides every face: adding a read in the middle changes the face of every seed. While the game is in alpha, saved seeds may change face, and the golden test in lib.rs is updated with the change.
