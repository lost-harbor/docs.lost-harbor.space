Module phrase 

Expand description

Phrases: templates that join chains, literals and other phrases.

A chain (a Style) writes one kind of word, such as a given name. A Phrase writes a whole line from one or more patterns. A pattern is plain text with slots in angle brackets:

SlotWrites
<chain:human:first>a name from the chain or phrase with that id
<chain.human.first>the same: a dot reads as a colon
<human:full|thren:full>one of the choices, picked evenly
<'the '|''>a quoted literal, here the or nothing
<#>one digit
<@>one capital letter
<<a plain <

A > outside a slot is plain text, so markup such as {grad:teal>blue} passes through.

So <chain:human:first> <chain:human:last> writes a full name, and <chain:house:name> <@><#><#> writes a gun model such as Brasker K40.

Braces are not used, because the text markup in lh_markup already uses {red} and {{.

A phrase with many patterns picks one at random each time, in proportion to the pattern weights (see crate::weighted). A pattern with weight 3 is picked three times as often as one with weight 1.

A Library holds every chain and phrase and runs templates. It also makes distilled chains (see crate::Distill): it runs the recipe’s template, then trains a chain on what it wrote.

Patterns: interpreter, since parse turns a template into pieces that Library then runs. Composite, since a phrase can hold other phrases. Memoization, since the library builds each chain once.
