lh_names

Module corpus 

Expand description

The name corpus: hundreds of real-world name lists, packed for loading on demand.

The raw lists live in game/data/names/<group>/<list>.txt. They are too large to embed in the game, and most of them sit unused at any moment. So a build step precomputes a pack (see the import-names command in lh_content):

  • One file per list, <group>/<list>.txt, with the setting filter applied, repeats joined and every line checked. A reader trusts it and only splits lines.
  • One index.json with an Entry per list: its id, its facet, its size and the length limits that suit it. A browser lists 600 chains from this one small file and fetches a list only when it opens.

A pack holds samples, not trained chains. A trained chain counts every run of letters, so it is larger than its list: the whole corpus has 2.3 million runs at order 3 and 11.5 million at order 5. Training one list takes a few milliseconds, so a reader trains on first use and keeps the chain.

Pattern: facade. entry and style are the only ways to turn a list into an index entry or a chain, so the builder, the lab and the game agree on ids, facets and limits.
