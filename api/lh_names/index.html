Crate lh_names 

Expand description

Names in a style, from a Markov chain over sample names.

A Style is a list of sample names and a few settings. The chain learns which letter tends to follow each run of letters in the samples. It then writes new names one letter at a time, so a new name sounds like the samples without being one of them. The same style and seed always give the same names, on the server and in the browser.

How it works:

  • Chain::new counts, for every run of 1 to order letters in the samples, how often each letter follows it. A start mark pads the front of each sample and an end mark closes it, so the chain also learns how names begin and end.
  • Chain::name starts from the start marks and picks each next letter by those counts, with the longest run it knows. With wander above zero it sometimes uses a shorter run, which makes bolder names.
  • Chain::names keeps drawing until it has enough names that pass the filters: the length limits, not a sample, not seen before, and no banned root (see is_banned).

Pattern: builder. Chain::new does the costly counting once. Each name after that is a cheap walk through the counts.

The corpus module describes the pack of large real-world lists that the importer writes and the name lab fetches on demand.
