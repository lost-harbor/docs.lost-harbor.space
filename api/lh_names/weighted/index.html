Module weighted 

Expand description

Weighted entries: a chain sample or a phrase pattern with a weight.

A sample with weight 120 counts as 120 copies of itself when the chain learns, so common names shape the chain more than rare ones. A phrase pattern with weight 3 is picked three times as often as a pattern with weight 1.

In a content file, an entry with weight 1 is a plain string, and any other entry is a pair:

samples: ["Tovik", ("Smith", 120)],

In a text box or a data file, each line holds one entry. An optional weight follows a tab: Smith<TAB>120. A line with no tab has weight 1.

Rust note: #[serde(from = .., into = ..)] reads and writes the struct through another type. Here that type is an untagged enum, so serde tries each shape in turn: a string, then a pair.
