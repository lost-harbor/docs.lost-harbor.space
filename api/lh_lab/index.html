Crate lh_lab 

Expand description

Generator labs: small pages that run one generator on its own.

The game draws ship schematics, side profiles and faces from small inputs. Tuning those inside the full game is slow: build, sign in, walk to a shipyard, look. A lab page loads the same drawing code with the embedded content and nothing else, so a change shows at once.

The page at web/lab/index.html loads this module. The path picks the lab, and ROUTES lists every path:

  • /lab/ships/: the ship lab in ships, with its overviews at /lab/ships/lineup/ and /lab/ships/grid/.
  • /lab/portraits/: the face lab in portraits.
  • /lab/names/: the name style lab in names.
  • /lab/: an index with links to each lab.

The game server answers every path under /lab/ with the lab page, and the Pages package copies the page into each route’s folder.

Pattern: front controller. One entry point reads the address and hands the page to one lab.
