lh_lab

Module ships 

Expand description

The ship lab: one ship at a time, built from a body, a paint scheme and a room layout, with every setting open for live edits.

The main view has three columns:

  • Left: the inputs, one compact picker each: the body (the house look, which the content calls a style), the hull class, the room layout and the paint scheme. The layouts are the sample decks of the class from samples, or a random deck from random_layout. The shipped ships come last, in a list of their own.
  • Centre: the ship. Four tabs show it: Normal (the drawn sheet), Schematic (the line sheet), Model (the rough 3D volume) and Deck plan (the rooms of each deck, as in the game’s ship panel). Each tab pans, zooms and fits.
  • Right: the settings. The model layer, the body layers, the paint, the room sizes and the RON to paste into the content files. A setting left unset names the value that it resolves to, and a setting that changes nothing for this ship is hidden.

The bar switches to two overview views. Line-up shows every shipped ship. Grid shows the current class in every body, on every sample layout of the class. Each view has its own path, and the picks live in the query, so a reload or a shared link shows the same ship. Keyboard shortcuts step the pickers.

Every drawing uses the game’s own components, so the lab shows what the game shows. Nothing is saved: the RON box prints the edits.

Pattern: Model View. Shared signals are the model. The plan is derived from them in one place, and every view reads it.
