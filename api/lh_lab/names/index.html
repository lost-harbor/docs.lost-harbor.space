lh_lab

Module names 

Expand description

The name lab: compose phrases from chain sources and weighted patterns.

A chain in content/names/<id>.ron is a Markov chain over a list of sample names (see lh_names). A phrase in content/phrases/<id>.ron joins chains and fixed text with templates such as <chain:human:first> <chain:human:last>. The lab loads the shipped records, lets the user change every field, and writes a fresh batch on each change.

Phrases are the authoring surface. Their tags go into content text. Each pattern has its own template field and weight. Source buttons insert a slot at the active pattern cursor without leaving the phrase editor.

The tools:

  • A click on a good name in the list adds it to the samples, so the chain learns from the names the user likes. This is the curation loop: write, pick, write again.
  • “Import file” reads a data file with one entry per line and an optional tab and weight, and opens it as a new chain with the id chain:import:<file name>.
  • The phrase list stays above the source browser. A phrase can also insert another phrase into a pattern.
  • “Inspect” opens a chain editor. “Back to phrase” restores the phrase, including unfinished pattern weights.
  • The template box in chain inspection runs any template against the records.
  • A distilled chain learns from a recipe. “Freeze samples” copies the recipe output into the samples and drops the recipe.
  • “Clean list” tidies a pasted list: it keeps the first column of a CSV line and a number in the second column as the weight, joins repeats, and fixes names typed in capitals.

The box at the bottom holds the record as RON, ready to paste into a content file. The same records also work in the game through the builder command names <id>.

Opened from lh_server, the lab loads the chains and phrases that the content files hold. “Save phrase” writes the open phrase to content/phrases/ and imports each corpus list it reaches as a chain file. The game reloads and the tag works at once. “Delete phrase” asks first, and the server refuses while a record still uses the tag. A dot in the phrase list marks unsaved changes. Opened from any other web server, the lab keeps phrases only until the page closes.

The source browser has two tabs. “Content” holds shipped and edited chains. “Corpus” browses over 600 real-world lists by region, topic and source group. Search finds sources by id or display name. Lists are fetched only when inspected or reached by a pattern through the corpus loader. The scoped importer turns only a saved phrase’s missing corpus dependencies into game content. The rest of the pack stays outside the game binary.

Pattern: model view. The records are signals. A memo builds a Library over them with the open record’s edits, and the names grid redraws from it. Trained chains stay in a cache between runs, so a list of 5,000 names trains once, not on every keystroke.
