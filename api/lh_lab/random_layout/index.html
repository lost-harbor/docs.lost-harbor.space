Module random_layout 

Expand description

Random room layouts for the ship lab.

The sample layouts in samples show a few hand-made decks per class. A random layout shows how a body copes with shapes nobody drew: lopsided wings, long spines, stacked decks. The result is written in the same letters as the samples, so a good roll can be pasted into samples.rs.

The limits come from the class’s own samples: the room count runs from the smallest sample to a quarter more than the largest, and the width, the length and the number of levels stay near the samples. The rooms other than the cockpit, the engines and the lock are drawn from the letters that the class’s samples use, so a hauler gets holds and a yacht gets lounges.

The shape grows from the cockpit at the bow, one room at a time, next to a room already placed. About half the rolls mirror each new room across the middle line, so some ships come out bilateral and the rest come out odd.

Pattern: Generate and test. A roll that breaks a rule is dropped, and the next seed is tried.
