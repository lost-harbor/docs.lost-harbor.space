Crate lh_protocol 

Expand description

Wire protocol between a Lost Harbor client and server.

The same messages travel over every transport: an in-browser Web Worker (single-player, GitHub Pages), or a WebSocket to the native server (local development now, hosted multiplayer later). Messages are JSON, internally tagged by t.

Text the player reads (Line::text, names, descriptions, chat) is colour markup in the lh_markup grammar, e.g. {teal}lit{/} or {cmd:look crate}crate{/}. The client renders it; the server never sends HTML.
