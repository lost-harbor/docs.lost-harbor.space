Expand description

Optional shape settings for a ship model. The blueprint is still drawn from the rooms. These settings only change the parts around them.

Every field is an Option. None keeps the value of the layer below, such as the hull style or the class defaults. Some replaces it, so a layer can switch a part on and also switch it off again.

Rust note: #[serde(default)] on the struct fills every missing field from Default, so a ship file names only the settings it changes. With implicit_some in the RON file, pods: true reads as Some(true).

Fields§

§prow: Option<Prow>

The prow shape.

§drive: Option<HullDrive>

The main drive.

§engines: Option<u8>

The most drive units that sit side by side across a wide stern. A large hull then carries an array of drives instead of one huge drive. One keeps a single main drive on every hull.

§drive_groups: Option<u8>

How many groups the drive units split into. One keeps a single row. Two parts the row into a mirrored pair of groups with open stern plate between them, so the thrust stays balanced.

§sheer: Option<Sheer>

How the roof and keel run from bow to stern.

§cut: Option<f64>

How far the hull outline may cut into the corners of the rooms, in cells, for smoother and more stylised shapes. The rooms are not square boxes inside, so a cut corner reads as a bevelled room.

§ridge: Option<f64>

How far the roof pitches down to each wall, from 0 for a flat roof to 1 for a steep ridge. The ridge keeps the roof height of the side view, so only the front view and the shading change.

§greebles: Option<f64>

How much small working gear covers the skin, from 0 for a clean hull to 1 for a hull crusted with boxes, pipe runs, tanks and doubler plates. The gear breaks up large flat faces in every view.

§livery: Option<Livery>

The paint rhythm of the drawn views.

§wear: Option<f64>

The age of the hull, from 0 for new to 1 for very old. Age adds repairs, refits and repaints to the drawn views. With no value, the age comes from a hash of the ship name.

§beam: Option<f64>

The clearance from a room box to the hull wall, in cells.

§corners: Option<Corners>

The cut where the hull steps from one row to the next.

§form: Option<Form>

How the width runs from bow to stern.

§massing: Option<Massing>

How room purpose zones compose into hull masses.

§joinery: Option<Joinery>

How the maker joins and lays out the outer hull skin.

§section: Option<Section>

The transverse construction around the occupied core.

§belt: Option<bool>

True for a band of armour plate along the widest rows.

§turrets: Option<u8>

The number of point defence turrets: 0, 2 or 4.

§fins: Option<bool>

True for swept fins on the stern quarters.

§wings: Option<Wings>

The wings on the sides.

§pods: Option<bool>

True for two long tank sponsons that hug the hull walls.

§spine: Option<f64>

The length of an open truss between the last room row and the drive, in cells. Zero means no spine.

§containers: Option<bool>

True to clamp cargo containers along both sides of the spine.

§island: Option<bool>

True for a raised superstructure over the bridge, with a mast.

§mounts: Option<u8>

The number of heavy gun mounts on the centre line of the deck.

§cranes: Option<bool>

True for cargo cranes beside the hold.

§boats: Option<bool>

True for launch boats hung in davits along the sides.

§kit: Option<HullKit>

The kit of hull parts that the generator fits to the rooms.

pub fn is_plain(&self) -> bool

pub fn over(&self, base: &HullShape) -> HullShape

These settings laid over base, such as the look of a hull style.

A setting that this shape names wins. A setting that it leaves out keeps the base value.

Rust note: Option::or keeps the first value when it is Some and falls back to the second one otherwise.
