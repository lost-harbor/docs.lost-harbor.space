Module room_flags 

Expand description

Room flags and room sizes.

A room flag is one bit in a RoomFlags set, in the way of the classic MUD room bits such as ROOM_PEACEFUL. A set of bits is small, cheap to test, and closed: a typo in a content file is an error at load time, not a flag that silently does nothing.

The flags fall in two groups. The room group works in any room. The ship group says what a ship room is for. Only the ship schematic reads it, so the builder shows it only for rooms that belong to a ship.

A content file still writes the flags as a list of names, such as flags: ["safe", "rent"]. The serde code below turns the list into bits and back.
