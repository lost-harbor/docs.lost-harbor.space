Crate lh_markup 

Expand description

Brace-tag color and style markup for text output.

The engine writes text with inline tags, such as {red}warning{/}. This crate turns that text into Span values. A span is a run of text with one Style and at most one Link. Clients draw each span with its style. The crate also checks markup for mistakes and removes links from text that players write. It has no game logic and no I/O, so every host can share it.

Grammar summary: {red}..{/} colors, {bright-teal}, {b}, {i}, {u}, {dim}, {pulse}, {grad:a>b} and {sweep:a>b} gradients, {bg:amber} backgrounds, and links {cmd:look}, {npc:ID}, {player:NAME}, {item:ID}, {exit:DIR}. {/} closes the innermost open tag, {{ is a literal {, and unknown tags render as literal text.

Functions§

escape
Escapes user text so that it renders literally inside markup. Each { becomes {{. parse turns {{ back into one {.
parse
Parses markup into styled spans. Adjacent spans with identical style and link are merged. A gradient applies across the characters of its span.
sanitize_player
Removes command and entity links from player-authored markup while keeping colors and styles. Text is re-escaped so the result never creates a link.
strip
Returns the plain text of src with all tags removed and escapes resolved.
validate
Lists problems in src: unknown tags, unterminated braces, unclosed or stray tags, and link tags when allow.links is false. Empty when clean.
