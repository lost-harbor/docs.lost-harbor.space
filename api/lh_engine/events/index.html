Module events 

Expand description

Typed events and the observers that react to them. A small typed event bus (Observer pattern). Systems emit events. The engine dispatches them to observers registered with AppBuilder::observe after each command and tick. Publishers never know their subscribers. New features can react to existing events without touching the code that raises them.
