Module parse 

Expand description

Command-line parsing. Command-line parsing: ; chaining, verbs, directions and keyword targets such as 2.ore, all.ore and 5 ore.

The parser turns one raw input line into three things: a verb, its arguments, and (for object commands) a Target. It does no game work. It is a set of pure functions, so the unit tests at the bottom need no world.
