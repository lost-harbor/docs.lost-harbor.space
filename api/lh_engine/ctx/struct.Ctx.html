Struct Ctx 

pub struct Ctx<'w> {
    pub world: &'w mut World,
    pub actor: Entity,
    pub exec: Option<ExecId>,
}
Expand description

A command executing on behalf of actor (player, simulated player or NPC).

Rust note: 'w is a lifetime. It says the &mut World inside lives no longer than the Ctx. While a Ctx exists, nothing else can borrow the world.

Fields§

§world: &'w mut World

The shared world. Systems read and write through this.

§actor: Entity

The entity running the command.

§exec: Option<ExecId>

Which submitted line this command came from, for replies.
