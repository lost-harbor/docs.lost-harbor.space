Expand description

Everything plugins registered. The engine keeps this in an Arc once built, so it cannot change.

Rust note: Default gives an empty value of every field. Each Vec starts empty.

Fields§

§commands: Vec<CommandSpec>

Command handlers, in registration order.

§fallbacks: Vec<FallbackFn>

Handlers tried when no command name matches.

§messages: Vec<MessageFn>

Handlers for messages that are not commands, such as login.

§views: Vec<ViewSpec>

View builders. The highest priority per name wins.

§movers: Vec<MoverFn>

Movement claims, tried in order.

§exits: Vec<ExitProviderFn>

Functions that add dynamic exits to a room.

§resolvers: Vec<ResolveFn>

Functions that pick the real room when an entity is placed.

§presence: Vec<PresenceFn>

Functions that list what is in a room.

§verbs: Vec<VerbFn>

Sources of verbs for a target, such as “take” for an item.

§lookers: Vec<(i32, LookFn)>

Look handlers with their priority.

§markers: Vec<MarkerFn>

Map marker sources, asked about each room the map shows.

§contacts: Vec<ContactFn>

Chart contact decorators, run in order for each viewer.

§records: Vec<RecordKind>

Record kinds to save and load.

§persist: Vec<PersistSection>

Character document sections.

§content_kinds: Vec<ContentKindSpec>

Content kinds the builder can edit, in registration order.

§control_groups: Vec<ControlGroupView>

Feature-owned group descriptors for configurable control items.

§content_checks: Vec<ContentCheckFn>

Feature-owned checks that also need the live plugin registries.

§control_verbs: Vec<ControlVerbRule>

Capability rules contributed by control-enabled features.

§startup: Vec<StartupFn>

Functions run once when the engine starts.

Plugin names, in the order they were added.

Component type names, for the record of what was registered.

Event type names, for the record of what was registered.

impl Registries

pub fn resolve(&self, verb: &str) -> Vec<&CommandSpec>

Handlers for a typed verb: exact names/aliases first, then abbreviations in registration order. Several handlers can share a name (highest priority first).

pub fn resolve_abbrev(&self, verb: &str) -> Vec<&CommandSpec>

Finds the first command whose name starts with verb and whose min is met. Then returns its handlers.

Rust note: let ... else runs the else block when the pattern fails. Here it returns early with no handlers.

pub fn view_names(&self) -> Vec<String>

Every distinct view name, in priority order.
