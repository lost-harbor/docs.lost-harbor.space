Struct AppBuilder 

pub struct AppBuilder {
    pub world: World,
    pub reg: Registries,
    /* private fields */
}
Expand description

Collects plugin registrations, then becomes an engine.

The builder owns a bevy World for components and resources, and three bevy Schedules, one per Stage.

Fields§

§world: World

The bevy world that components and resources are registered into.

§reg: Registries

What plugins have registered so far.

impl AppBuilder

pub fn new() -> Self

An empty builder with no plugins registered.

pub fn add_plugin(&mut self, plugin: impl Plugin) -> &mut Self

Records the plugin’s name, then calls its build.

Rust note: impl Plugin in argument position accepts any type that implements the trait. The compiler makes one copy per type (static dispatch).

pub fn command(&mut self, spec: CommandSpec) -> &mut Self

Adds a typed command. See CommandSpec.

pub fn fallback(&mut self, f: FallbackFn) -> &mut Self

Adds a fallback, tried when no command name matched exactly.

pub fn on_message(&mut self, f: MessageFn) -> &mut Self

Adds a client-message handler. Handlers run in order until one returns true.

pub fn view(&mut self, name: &str, priority: i32, build: ViewFn) -> &mut Self

Registers a view. For one name, the highest-priority view returning Some wins.

pub fn mover(&mut self, f: MoverFn) -> &mut Self

Adds a mover. The first mover that returns Some handles the move.

pub fn resolver(&mut self, f: ResolveFn) -> &mut Self

Adds a room resolver. See ResolveFn.

pub fn exit_provider(&mut self, f: ExitProviderFn) -> &mut Self

Adds dynamic exits to rooms. See ExitProviderFn.

pub fn presence(&mut self, f: PresenceFn) -> &mut Self

Adds room contributions for the room text and the RoomView. See PresenceFn.

pub fn verbs(&mut self, f: VerbFn) -> &mut Self

Adds verbs for targets. See VerbFn.

pub fn looker(&mut self, priority: i32, f: LookFn) -> &mut Self

Adds a look <word> describer. Higher priority values run first.

pub fn marker(&mut self, f: MarkerFn) -> &mut Self

Adds a map marker source. See MarkerFn.

pub fn records(&mut self, kind: RecordKind) -> &mut Self

Adds a family of persisted records. See RecordKind.

pub fn persist( &mut self, key: &str, save: fn(&World, Entity) -> Value, load: fn(&mut World, Entity, &Value), ) -> &mut Self

Adds a section to each character’s saved document. key names the section in the file.

pub fn contact(&mut self, f: ContactFn) -> &mut Self

Adds a chart contact decorator. See ContactFn.

Design pattern: Decorator. The space plugin builds plain contacts. Each decorator adds one layer of what the viewer knows, without the space plugin knowing about it.

pub fn content_kind(&mut self, spec: ContentKindSpec) -> &mut Self

Adds a content kind to the builder. See ContentKindSpec.

pub fn on_startup(&mut self, f: StartupFn) -> &mut Self

Runs f once when the engine starts. See StartupFn.

pub fn component<C: Component>(&mut self) -> &mut Self

Registers a component type with the ECS world.

Rust note: <C: Component> is a generic parameter with a bound. The bound says C must be a bevy component. Call it as .component::<Hp>().

pub fn resource<R: Resource>(&mut self, r: R) -> &mut Self

Inserts a global resource, such as a clock or RNG, that systems can read.

pub fn event<E: Any + Send + Sync>(&mut self) -> &mut Self

Declares an event type for documentation and introspection. Any 'static type can still be emitted.

pub fn observe<E: Any + Send + Sync>( &mut self, f: fn(&mut World, &E), ) -> &mut Self

Observes an event type (Observer pattern). Observers run in registration order.

Rust note: fn(&mut World, &E) is a function pointer. The move closure below captures f by value, so the observer owns it.

pub fn systems<M>( &mut self, stage: Stage, systems: impl IntoScheduleConfigs<ScheduleSystem, M>, ) -> &mut Self

Adds bevy systems to a tick stage. Pass one system or a tuple of them.

Rust note: M is a marker type that bevy uses to tell apart the kinds of function it accepts. You never name it yourself.
