Expand description

A feature module. Implement build to register the feature’s pieces.

Rust note: a trait lists the methods a type must provide. name has a default body, so a plugin only writes build unless it wants its own name.

Required Methods§

fn build(&self, app: &mut AppBuilder)

Registers commands, views, systems and anything else this feature adds.

Provided Methods§

fn name(&self) -> &'static str

The name listed in the registry. Defaults to the Rust type name.
