Struct Engine 

pub struct Engine { /* private fields */ }
Expand description

Re-exports the host API. One running game world. Synchronous: the host drives it with handle and tick and collects output with drain and take_dirty.

Rust note: Engine is a facade. It hides the ECS World, the schedules and the registries behind a few plain methods.

Describes the host in the Hello reply. server, transport and storage are labels.

pub fn connect(&mut self) -> SessionId

Opens a new session with no character yet. Send it messages with handle.

pub fn disconnect(&mut self, session: SessionId)

Removes a session. If it had a character, the character leaves the world and is saved.

pub fn handle(&mut self, session: SessionId, msg: ClientMsg)

Handles one client message for a session.

Commands go to the action queue. Stop cancels the queue. Any other message goes to the message handlers, which run until one returns true. An unknown session is ignored.

Rust note: match (&msg, character) matches on a pair. The _ arm catches every message that the first two arms did not match.

pub fn tick(&mut self, now_ms: u64)

Advances time to now_ms (host milliseconds; monotonic).

Time never goes backwards. An older now_ms is ignored. Each schedule runs in order (First, Update, Last), and events are dispatched after each.

pub fn drain(&mut self, session: SessionId) -> Vec<ServerMsg>

Takes every message waiting for a session, leaving its outbox empty.

Rust note: std::mem::take swaps the outbox for an empty one and returns the old value. No copy is made.

pub fn take_dirty(&mut self) -> Vec<Record>

Records changed since the last call. The host must persist them.

pub fn reload_content(&mut self, content: Content)

Swaps in new content (rooms, descriptions, items, NPC text) without a restart. Spawned instances stay where they are.

Builder edits that the host has not written yet stay on top of the new content. See crate::edits.

pub fn forget_content_edits(&mut self)

Drops the pending builder edits, because the host has written them to the content files. A later reload reads them from the files.

It also forgets the stored hashes of content records. Otherwise an edit that matches an old save would look unchanged and never reach the files again.

pub fn sessions(&self) -> Vec<SessionId>

Every open session id.

pub fn registries(&self) -> &Registries

The frozen registries, for hosts that list commands or views.

pub fn world(&self) -> &World

Read-only access to the ECS world, for tests and inspection.

pub fn world_mut(&mut self) -> &mut World

Mutable access to the ECS world. Changes made here skip the usual message flow.
