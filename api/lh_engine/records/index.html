Module records 

Expand description

Records that the host persists between runs. Persistence plumbing. Record kinds are registered by plugins. The engine diffs their current records against what the host last stored.

Two kinds of saved data exist. Records (RecordKind) are whole files, such as a room or a user, and are diffed by hash. Character documents are JSON objects built from PersistSections, one section per plugin.
