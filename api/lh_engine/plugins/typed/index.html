Module typed 

Expand description

Typed commands for everything the windows do: builder edits and player gaps. Typed builder and player commands: everything a window does, by typing.

Lost Harbor is a MUD, so each window is a convenience on top of commands. This plugin adds the commands that the windows had and typing lacked.

The builder commands do not change content directly. Each one sends the same content API operations as the builder windows (Kinds, List, Get, Put, and Delete) through the shared content API. So a typed change gets the same rights check, the same validation, the same save, and the same live update in open editor windows as a change made in a window.

The modules:

  • path: JSON field paths such as exits.0.distance.
  • api: runs one content operation and turns the reply into text.
  • generic: clist, cshow, cset, cadd, cdel, cnew, cdelete, cexport, and cimport, for every content kind.
  • records: zedit, medit, oedit, shopedit, jobedit, hedit, and build off.
  • room: redit subcommands, dig, and exit.
  • system: sysedit.
  • behavior: bedit.
  • player: group.
