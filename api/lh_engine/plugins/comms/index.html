Module comms 

Expand description

Talking: say, emote, tells, channels, OOC and who. Talking: say, emote, socials, tells and replies, station channels, OOC and who. Player-authored text is always passed through lh_markup::sanitize_player (colours allowed, links stripped).

This plugin registers:

  • Content kind: social, so the builder can edit socials.
  • Component: LastTell, the name of whoever sent this character their last tell.
  • Resource: CommSeq, a counter that gives each message a unique id.
  • Events: Spoke, TellReceived, and ChannelPost, so other plugins can react to talk.
  • Commands: say, emote (alias me), tell (aliases whisper, page), reply (alias r), chat (alias station), faction (alias fc), ooc, who, and socials.
  • Fallback: social_fallback runs when a typed word is not a command. It looks the word up in the content’s socials list.
  • Message hook: on_comm handles ClientMsg::Comm, which is the comms panel’s direct path. It skips typed commands.
  • Observer: deliver_post sends each ChannelPost to every connected player.
  • View: who (who_view), for the online list panel.

Independence: this plugin depends on clock for time_str, which stamps every comm message. Other code reaches it through the Spoke, TellReceived, and ChannelPost events and through the public send_tell function. Sims use the normal say and tell commands, like players do.
