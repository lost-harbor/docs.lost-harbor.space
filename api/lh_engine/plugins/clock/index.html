Module clock 

Expand description

Station time: a day counter and a minute of the day, advanced from the host clock. The clock plugin. It keeps station time: a day counter and a minute of the day, advanced from the host clock.

It registers the Clock resource, a startup function that sets the start time, a First-stage system that advances the clock each tick, the clock view that sends the time to the client, and the time command. Other plugins read the clock through the Clock resource or the time_str helper. The comms plugin calls time_str for message timestamps. This plugin imports nothing from other plugins.
