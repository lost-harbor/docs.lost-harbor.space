Expand description

Builds the deck plan of ship p for viewer, who stands in here. The shipyard calls it with a template and an empty here to draw a ship for sale. The map layout walks out from map.here, so an empty here starts the walk at the cockpit. Without a start room the layout places no rooms, and the hull shrinks to a stub.

Every room of the ship is on the plan, because a ship carries its own plan. A room counts as visited only when the viewer has been there, which is what walk needs. Exits to rooms outside the ship lose their to, so the client draws them as hatches in the hull.
