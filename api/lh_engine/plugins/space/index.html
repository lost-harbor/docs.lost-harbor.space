Module space 

Expand description

Space: star systems, flight, fuel, gates, regions, traffic and ship records. Space: ships flying between places on a system chart.

Space has no rooms. A ship is a zone of rooms that people walk around in, and the ship itself sits at a place, flies a course, or drifts at a point. This module holds the shared state and helpers. The submodules add the commands and the tick work:

  • flight: launch, dock, fly, hold, status, arrivals, and the switch to reserve thrust when the tank runs dry.
  • fuel: fuel drawn per flight, refunds, and refuel.
  • gates: jump between paired gates.
  • regions: mine, salvage, and scan.
  • traffic: NPC ships, contacts, hail, and transcript traffic lines.

The plugin registers:

  • Content kinds: ship applies ship edits, and system synchronizes traffic.
  • Resources: Ships and SpaceTime. Traffic adds NpcShips and TrafficLog.
  • Startup initializes ships and NPC traffic.
  • Systems start the epoch in First and advance space in Update.
  • View: ship, a ShipView for everyone aboard a ship.
  • Records: kind ship, one per player ship, and kind space, the clock.

Time: system time is real seconds since the clock started, times the system rate. The clock resumes from the last saved value after a restart, so ships in flight continue where they were.

The System and Contacts messages carry live positions. A hashed view resends a message only when its JSON changes, and a live time changes every tick. These two are pushed on events through push_charts and push_contacts, to everyone at a helm in the system.

Modules§
