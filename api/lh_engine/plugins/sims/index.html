Module sims 

Expand description

Simulated players: they wander, chat, say things and answer tells. Simulated players: they wander, chat on channels, say things to people nearby, answer tells, and greet newcomers with one unsolicited tell. Sims act through the same command pipeline as players (queue::execute), so they obey every rule a player does.

This plugin registers:

  • Content kind: sims, the single record with the simulated players and chatter.
  • Components: Sim (per-sim state: which sim it is, when it acts next, who it has greeted). It also registers Doing, which holds the sim’s status line.
  • A resource: Chatter, which tracks when the next channel line is due.
  • A startup hook: spawn_sims creates one entity per sims entry in the content.
  • Observers: answer_tell for TellReceived, and greet for EnteredWorld.
  • Systems in Stage::Update: chatter and wander.

Independence: this plugin imports only the core modules (queue, events, rng, world). It does not import any other plugin. Other plugins never import this one. It reaches players only through the events and commands the core already provides.
