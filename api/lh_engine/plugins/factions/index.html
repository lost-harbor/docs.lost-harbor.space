Module factions 

Expand description

Faction standings, scanned ships and hostile contacts. The factions plugin. It tracks each character’s standing with each faction, and which ship contacts the character has scanned.

It registers:

  • the faction content kind for the builder,
  • the Standing and Scanned components, saved in the factions section of the character document,
  • the standing command, which lists the standings,
  • an observer of Scanned, which records the scan and reports the ship’s faction,
  • a chart contact decorator, which sets known and hostile, and hides the details of ships the character has not scanned.

A ship is known to a character after one scan. Before that, the chart shows it only as UNKNOWN_NAME, with no class and no owner. Its position and course still show, because those are plain sensor returns. A known ship whose faction stands at or below Faction::HOSTILE_AT with the character is hostile. The chart then draws its course in red when it comes toward the character.

It reads the space plugin’s public push_charts, so a scan updates the chart at once. It changes no other plugin.
