Module shops 

Expand description

Shops: buying, selling and valuing with a shopkeeper NPC. Shops: buying and selling with a shopkeeper NPC in the room.

This plugin registers:

  • Content kind: shop, listed in the builder under the keeper’s name.
  • Commands: list, buy, sell, and value. value also answers to appraise.
  • A map marker: shop_marker puts a shop icon on rooms that have a shop.

It adds no components, resources, systems, or views of its own. A room counts as a shop when it has the shop flag or holds an NPC that a shop record names as its keeper. Shop data comes from lh_content, and the plugin reads it through world helpers.

Independence: sell and value call items::match_items to find items in the pack, so this plugin depends on items. buy uses rules::max_kg for the weight limit.
