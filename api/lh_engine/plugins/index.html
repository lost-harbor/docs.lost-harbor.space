Module plugins 

Expand description

The standard gameplay plugins. Standard gameplay plugins. Each one is self-contained: it registers its commands, views, observers and systems and depends mainly on the core (world, events, ctx, queue). A few import a sibling, such as shops using items, so the rule is core-first, not total isolation.

Each file in this folder, other than this one, is one plugin. Its module doc lists what it registers. To write a new one, start from CoinPlugin in tests/plugins.rs.
