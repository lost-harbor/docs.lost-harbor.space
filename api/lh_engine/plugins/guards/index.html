Module guards 

Expand description

Exit guards: content-driven checks that hold a character at an exit. The guards plugin. It holds a character at a guarded exit until the guard’s conditions hold.

A room lists its guards in content (guards on the room record). Each guard watches one exit. It is on duty while its NPC stands in the room, or always when it names no NPC. It lets a character pass when every allow condition holds. Otherwise:

  • the first try prints warn and sets the flag warned:<room>:<dir>.
  • each later try prints stun, moves the character to back_to, and keeps them busy for stun_secs.

When the guard stands down, the pass line shows once and sets the flag passed:<room>:<dir>. Rooms in these flags are base ids, so a guard in an instance copy shares its flags with the content room.

Design pattern: Chain of Responsibility. The guard is one more mover in the movement plugin’s chain. It answers only for a guarded exit and passes every other exit on.
