Module names 

Expand description

Name styles and the names command, from Markov chains in lh_names. The names plugin: chains, phrases and new names, for builders.

A chain is a content record of kind name, one file per chain in content/names/. It holds sample names and the settings of the Markov chain in lh_names. A phrase is a record of kind phrase in content/phrases/. It joins chains and fixed text into a line, for example <chain:human:first> <chain:human:last>. This plugin registers both kinds, so the builder and the generic typed commands (clist phrase, cadd name chain:spacer:given samples "Tovik") work on them with no extra code.

It adds one command, names (alias namegen):

  • names lists the chains and phrases.
  • names <id> [count] [seed] writes new lines from a chain or phrase. The reply shows the seed, so the same list can be made again.
  • names try <template> runs a template typed on the line.

It also adds reroll <item|npc|room> <id> [back]. Text in an item, NPC or room can hold slots such as <human:full>. The record’s id and its roll number seed them. reroll raises the roll by one, or lowers it with back, saves the record, and prints the new text. The id stays, so no reference to the record breaks.

The command checks builder rights through the content API, like every other building command. It reads the raw content, so it sees records the builder has just edited. It changes no world state.
