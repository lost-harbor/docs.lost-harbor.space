Module help 

Expand description

The help command, which lists commands from the registry. The help plugin. It lists the visible commands from the command registry, grouped by each command’s group name, or explains one command or group.

It registers one command, help, with the aliases ? and commands. It reads the registry through ctx.reg() and never calls another plugin. Any plugin that registers a command shows up here with no change to this file. This is the Registry pattern: the registry is the shared list, and readers such as this plugin query it.

Several plugins can register handlers under one name. For example, the typed builder adds subcommands to redit, and the building plugin’s redit opens the editor. help redit shows the text of every handler.
