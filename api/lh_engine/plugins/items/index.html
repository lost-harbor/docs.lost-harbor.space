Module items 

Expand description

Things: room items, picking up, dropping, giving, wearing and searching. Things: room items and fixtures, picking up, dropping, giving, wearing, inventory and equipment, prising fixtures open and searching for hidden things. Also owns the items section of the character document.

This plugin registers:

  • Content kind: item, so the builder can edit item prototypes.
  • Commands: get (aliases take, pick), drop, give, inventory (aliases i, inv), equipment (alias eq), wear (aliases wield, hold, equip), remove (alias unequip), open (hidden), and search.
  • Startup and reload: spawn_room_items places each room’s starting items. It runs again on ContentReloaded.
  • Observer: notice runs on Arrived, so arriving players see the items here.
  • Room hooks: item_presence lists items in a room, item_verbs adds the verbs for an item, and look_item adds to the look text (priority 20).
  • Persistence: the items section of each character, through save_items and load_items.

Independence: this plugin uses the world, rules, text, parse, and events core modules. It exports two helpers that other plugins import: match_items (used by shops) and item_view (used by character). Those helpers belong to this plugin, so the other plugins depend on items, not the other way round.
