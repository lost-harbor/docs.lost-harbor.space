Module world 

Expand description

Shared components and resources used across plugins. Shared components, resources and helper functions used across plugins.

This is the shared vocabulary of the game world. The engine keeps everything in one bevy_ecs World, which holds three kinds of data:

  • Entities are plain ids. An entity has no data of its own.
  • Components are structs attached to an entity, such as Person or InRoom. An entity is a player if it has a Person component.
  • Resources are structs with one copy per world, such as Live or Doors.

Systems and helpers find data by asking for a component or resource type. They never hold references to other plugins’ data, so a plugin only needs to know the types in this file.

Rust note: #[derive(Component)] and #[derive(Resource)] come from bevy_ecs. They mark a struct as storable in the world.
