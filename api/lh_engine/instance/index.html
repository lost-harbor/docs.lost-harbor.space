Module instance 

Expand description

The shared record of live instance copies, and the clock of each copy.

An instance group (the instance content kind, or an owned ship template) is a set of rooms. Each owner gets a private copy of those rooms. A copy room has the id <base room id>@<owner>, for example works:bay@ash-7. The owner is the lower-case character name.

This module holds only the data that several plugins read: which copies are live and what time it is inside each one. The instances plugin creates, saves, and drops copies. The behaviors plugin reads the day for the Day condition, and the clock view reads the time inside a copy through the instances plugin.
