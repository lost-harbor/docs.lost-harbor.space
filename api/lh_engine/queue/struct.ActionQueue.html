Struct ActionQueue 

pub struct ActionQueue {
    pub running: Option<Running>,
    pub pending: VecDeque<Pending>,
}
Expand description

The queue for one actor. Every actor has one, including NPCs.

Rust note: #[derive(Component)] makes this type an ECS component, so it can sit on an entity. Default gives an empty queue.

Fields§

§running: Option<Running>

The action in progress, if any.

§pending: VecDeque<Pending>

Command lines waiting behind it, first in line first.
