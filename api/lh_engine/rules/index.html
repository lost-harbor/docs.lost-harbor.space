Module rules 

Expand description

Dice rolls and the rules of the game. Rules: a 5e-derived sci-fi system in our own wording. d20 + ability modifier + proficiency (if trained) against a DC.

The rules are pure functions. They read content (Content.rules) and a character’s Stats, and return a number. Plugins call them, so a new skill or feature needs no change here unless it changes the maths.

The bonus or penalty for an ability score. 10 is 0, 16 is +3, 9 is -1.

The proficiency bonus at level. It starts at +2 and rises every four levels.
