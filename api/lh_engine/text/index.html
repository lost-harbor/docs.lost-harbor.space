Module text 

Expand description

Text helpers for articles, counts and markup links. Text helpers: articles, counts and lh_markup semantic links.

Functions here build display text. Links use markup such as {cmd:look} and {exit:north}, which the client turns into clickable spans.

Functions§

and_list
Joins with commas and “and”. ["a", "b", "c"] becomes a, b and c.
article
Returns “a” or “an” for a (possibly marked-up) noun phrase.
cap
Capitalises the first character of a plain string.
cap_markup
Capitalises the first visible letter of markup text, skipping leading tags.
counted
“a lump of ore”, “three lumps of ore”.
link_cmd
Links a command, for example {cmd:look}Look{/}. The {/} closes the link.
link_exit
Links an exit by direction, for example {exit:north}.
link_item
Links an item prototype by id.
link_npc
Links an NPC by id.
link_player
Player names are plain text by construction. The name is still escaped, to be safe.
listed
Bare name with a count for lists: “lumps of ore ×3”.
signed
Formats a signed number with an explicit + for zero and above.
