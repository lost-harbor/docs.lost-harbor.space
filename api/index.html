Public API documentation

These pages describe the public Rust library APIs. They exclude private items and generated source-code pages. Use the search box on a crate page to find types, functions and methods across the generated crates.

§Engine and contracts

  • lh_engine: ECS simulation, plugins, commands and host API.
  • lh_protocol: wire messages, requests and view models.
  • lh_content: world models, content loading and validation.
  • lh_store: records and persistence strategies.

§Hosts and interface

  • lh_server: native HTTP, WebSocket and storage host.
  • lh_worker: browser worker and IndexedDB host.
  • lh_client: Leptos components, state and browser transports.
  • lh_lab: standalone generator tools.

§Shared tools

  • lh_markup: game-text markup.
  • lh_map: room layout.
  • lh_space: orbit and flight math.
  • lh_portrait: seeded portrait drawing.
  • lh_names: Markov names, phrases and corpus metadata.

§Build context

The published tree uses the native workspace’s library targets and default features. The native server enables the SQLite storage feature. Browser APIs are also checked for wasm32-unknown-unknown. The developer guide explains the two hosts and local documentation checks.
