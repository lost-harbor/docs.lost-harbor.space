Expand description

One step that a rule performs.

Variants§

§

Say

The NPC says the text to the room.

Fields

§text: String

The words, as markup.

§

Emote

The NPC does something that the room sees, written after its name.

Fields

§text: String

The action, as markup, for example nods slowly.

§

Tell

The NPC tells the character the text. Nobody else sees it.

Fields

§text: String

The line, as markup.

§

Narrate

A line of narration for the character alone, with no speaker.

Fields

§text: String

The line, as markup.

§

Give

The NPC hands the character new items.

Fields

§item: String

The item prototype id.

§count: u32

How many. The default is one.

§

Take

The NPC takes items that the character carries.

Fields

§item: String

The item prototype id.

§count: u32

How many. The default is one.

§

Move

The NPC walks through an exit of its room.

Fields

§dir: Direction

The exit direction.

§

Open

The NPC opens the door of an exit in its room.

Fields

§dir: Direction

The exit direction.

§

Close

The NPC closes the door of an exit in its room.

Fields

§dir: Direction

The exit direction.

§

SetFlag

Sets a flag on the character.

Fields

§flag: String

The flag name.

§

ClearFlag

Clears a flag on the character.

Fields

§flag: String

The flag name.

§

StartJob

Gives the character a job, when the character has no active job.

Fields

§job: String

The job id.

§

AdvanceJob

Finishes the character’s active job, when it is this job. The pay and XP follow the job rules.

Fields

§job: String

The job id.

§

Wait

Waits before the next action.

Fields

§secs: f32

The pause in real seconds.

§

Run

Runs the Called rules of another behavior, with the same character.

Fields

§behavior: String

The behavior id.

§

Seal

Seals an instance group for the character: its copy and saved state are deleted for good, and its sealed flag is set. With None, the group is the one the character stands in.

Fields

§instance: Option<String>

The instance group id.

§

SetRespawn

Makes a room the character’s respawn point (the clone bay). A room in an instance group means the character’s own copy.

Fields

§room: String

The room id.

§

Teleport

Moves the character to a room. A room in an instance group means the character’s own copy.

Fields

§room: String

The room id.

§

Damage

Deals damage to the character, outside or inside a fight. A save, when set, avoids it or halves it.

Fields

§dice: String

The damage dice, for example 2d6.

§kind: String

The damage type, for example shock.

§save: Option<Save>

The save against it. None means no save.

§

Heal

Restores hit points to the character.

Fields

§dice: String

The dice, for example 1d8+2.

§

Afflict

Applies a condition, such as stunned, to the character.

Fields

§condition: String

The condition name.

§rounds: u32

How many combat rounds it lasts.

§save: Option<Save>

The save that avoids it. None means no save.

§

Attack

The NPC attacks the character and starts a fight. The NPC needs combat stats.
