Expand description

An item prototype. The world spawns item entities from it.

Fields§

§name: String

The singular name, for example “lump of ore”.

§plural: Option<String>

The plural name. Without it, the name gets an s.

§keywords: Vec<String>

Plain lower-case keywords. The first is primary and the rest are aliases.

§weight: f32

The weight in kilograms.

§value: i64

The base price in credits.

§stack: bool

True when copies merge into one stack.

§slot: Option<String>

The wear slot: outer, over, under, held, or belt.

§tool: Option<String>

The tool tag, for example “key” or “wrench”.

§armour: Option<Armour>

Armour stats, for items worn as armour.

§weapon: Option<Weapon>

Weapon stats, for items wielded in the held slot.

§consumable: Option<Consumable>

What use <item> does, for medkits and stims. One use spends one.

§fixed: bool

Fixtures cannot be picked up.

§unlisted: bool

Omit this room-described item from listings and pickup commands.

§mountable: bool

Users mount this item and leave it before walking.

§user_capacity: Option<u32>

Concurrent users of each copy. Unset means one.

§controls: Option<ControlSystem>

Optional Control System feature on this ordinary item.

§hidden: Option<u8>

The Perception DC to notice the item. A hidden item stays out of view until found.

§line: Option<String>

The room line. {N} becomes the counted name.

§look: Option<String>

What look <item> shows.

§opens: Option<Opens>

How a fixture opens with a tool to yield an item.

§roll: u32

Which roll of the phrase slots in this record’s text the game shows. 0 is the first. A builder rerolls to see other text with the same id. See seeded.
