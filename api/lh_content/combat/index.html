Module combat 

Expand description

Weapons, armour, abilities, NPC combat stats, and hazards. The combat data model: weapon and armour stats, consumables, class abilities, NPC combat stats, and room hazards.

Every type here is optional on its host record. A record without combat data loads as before, because each new field has a serde default. The engine’s combat plugin reads these types. The resolution follows 5e: a d20 roll plus a bonus against a target number.

Dice use the text form NdS+B, for example 1d8, 2d6+3, or 4. The Dice type parses that text and the validator checks it.
