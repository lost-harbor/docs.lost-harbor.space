Expand description

One effect of an ability, a consumable, or a behavior.

Design pattern: Interpreter. Content lists effects as data, and the engine walks the list and runs each one. New content needs no new code.

Variants§

§

Damage

Rolls damage against the target.

Fields

§dice: String

The dice, for example 2d6.

§kind: String

The damage type, for example shock.

§

Heal

Restores hit points to the target, up to its maximum.

Fields

§dice: String

The dice, for example 1d8+2.

§

Buff

Raises a combat stat for some rounds.

Fields

§stat: Stat

The stat that changes.

§amount: i32

How much it rises.

§rounds: u32

How many combat rounds it lasts.

§

Debuff

Lowers a combat stat for some rounds.

Fields

§stat: Stat

The stat that changes.

§amount: i32

How much it falls.

§rounds: u32

How many combat rounds it lasts.

§

Condition

Applies a named condition, such as stunned, for some rounds.

Fields

§name: String

The condition name. The engine knows stunned, prone, bleeding, burning, suppressed, blinded, aiming, dodging, and guarded.

§rounds: u32

How many combat rounds it lasts.

§

Attack

Makes a weapon attack with the wielded weapon, plus extra damage dice on a hit.

Fields

§dice: String

Extra damage dice on a hit, for example 1d6. Empty adds none.

§advantage: bool

True to roll the attack with advantage.

§

Cleanse

Removes every adverse condition from the target.
