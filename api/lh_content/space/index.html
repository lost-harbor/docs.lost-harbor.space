Module space 

Expand description

Star systems, places, NPC traffic, and ship drives. Space content: star systems, the places on their charts, NPC traffic, and ship drives.

A system file under content/systems/ holds one System. Space has no rooms. A place names a dock room when ships can dock there, and the dock room lives in an ordinary zone file. The engine turns these types into the wire types SystemView and PlaceView and moves ships with lh_space.

Units: positions and sizes are chart units (cu). Times are system seconds. Acceleration is cu per second squared and cruise speed is cu per second.
