Expand description

An NPC prototype. The world spawns NPC entities from it.

Fields§

§name: String

The lower-case name, for example “dock clerk”.

§short: String

The sentence-start form, for example “A dock clerk”.

§line: String

The room line after the short name.

§keywords: Vec<String>

Plain lower-case keywords that players use to name the NPC.

§level: u8

The NPC level.

§look: String

What look <npc> shows.

§say_name: String

The name used when speaking, for example “The dock clerk”.

§topics: BTreeMap<String, String>

Replies for ask <npc> about <topic>, by topic.

§default: String

The reply to talk and to unknown topics.

§hires: Vec<String>

Hireling ids that this NPC offers through hire.

§behaviors: Vec<String>

Behavior ids that this NPC runs, in order.

§combat: Option<NpcCombat>

Combat stats. Without them, the NPC cannot be attacked.

§absent_when: Vec<Condition>

Tests that remove the NPC from an instance copy. When every test holds for the copy owner, the NPC leaves the copy and does not spawn there again. An empty list keeps the NPC. Shared rooms ignore it, because they have no owner to test.

Rust note: skip_serializing_if leaves the field out of saved files when the list is empty, so most NPC records stay short.

§portrait: u64

The face seed drawn for this NPC. Zero draws a face from the content id, so every NPC of one kind shares a face.

§face: String

The portrait generator for a creature, such as beast:rat, machine:wedge or alien. The part before the colon names the family and the part after it names the form. An empty string draws a person. The content id still picks the details, so every NPC of one kind shares a face.

§faceless: bool

True for vents, presses, voices and anything else with no face to draw. The client shows an icon for them instead.

§roll: u32

Which roll of the phrase slots in this record’s text the game shows. 0 is the first. A builder rerolls to see other text with the same id. See seeded.
