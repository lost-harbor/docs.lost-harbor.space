Crate lh_content 

Expand description

Hand-built world content for Lost Harbor.

Content lives under game/content/ as one RON file per record, for example rooms/spindle/concourse.ron for the room spindle:concourse. The build.rs script embeds every file, so the WebAssembly build needs no file system. Native hosts also read the tree from disk, which lets the server hot-reload it and write builder edits back.

Modules:

  • model: the record types, one map per kind in Content.
  • behavior: the NPC behavior model of triggers, conditions, and actions.
  • kinds: the kind table that reads and writes records as JSON and RON.
  • tree: the file layout, the loaders, and the writers.
  • validate: cross-reference checks with field paths.
  • space: star systems, places, NPC traffic, and ship drives.
  • deck: the deck plan of a ship, shared by the engine and the labs.
  • combat: weapons, armour, abilities, NPC combat stats, and hazards.

Functions§

check_id
Checks a record id. Ids are lower-case words of letters, digits, -, and _, joined by :. A singleton’s only id is its kind key. Returns the reason when the id is not allowed. Each kind declares its required namespace.
clock_minute
Parses HH:MM into a minute of the day, from 0 to 1439.
kind
The table row for a kind key, such as room.
parse_path
The kind and id of a file, from its path relative to the content folder, written with /. Returns None for a path that is not a record file.
record_path
The file of one record, relative to the content folder.
ron_options
The RON options for reading content: Some is implicit, so pin: (1, 2, 0) reads as Some((1, 2, 0)).
split_owner
Splits a room or ship id into its base id and its owner. works:bay@ash-7 gives ("works:bay", Some("ash-7")), and a shared id such as spindle:concourse gives ("spindle:concourse", None).
with_owner
Joins a base id and an owner into a copy id, as works:bay@ash-7. A base id that already has an owner is returned unchanged.
write_record_json
Writes or removes one record file from its JSON form. Hosts use it to persist builder edits. data of None or JSON null removes the file. Returns the file path that changed.
