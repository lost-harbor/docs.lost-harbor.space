Expand description

One complete, merged content bundle: every record of every kind.

Rust note: BTreeMap keeps its keys sorted. Sorted keys give a stable order for lists, exports, and file writes.

Fields§

§zones: BTreeMap<String, Zone>

Zones (areas) by id, for example spindle.

§rooms: BTreeMap<String, Room>

Rooms by id, for example spindle:concourse.

§items: BTreeMap<String, ItemProto>

Item prototypes by id, for example ore.

§npcs: BTreeMap<String, NpcProto>

NPC prototypes by id, for example clerk.

§shops: BTreeMap<String, Shop>

Shops by id. Each shop names the NPC that keeps it.

§behaviors: BTreeMap<String, Behavior>

NPC behaviors by id. NPCs list the behaviors they run.

§rules: Rules

The rules data: classes, skills, the XP table, and the start kit.

§socials: BTreeMap<String, Social>

Socials by verb, for example wave.

§sims: Vec<SimPlayer>

Simulated players, in a fixed order. The sims plugin indexes them.

§chatter: Vec<Chatter>

Channel chatter lines, in the order they play.

§jobs: BTreeMap<String, Job>

Jobs on the tally board, by id.

§hirelings: BTreeMap<String, Hireling>

Hirelings by id, for example oona.

§ships: BTreeMap<String, Ship>

Player ship prototypes by id, for example wren.

§systems: BTreeMap<String, System>

Star systems by id, for example verge.

§instances: BTreeMap<String, InstanceDef>

Instance groups by id, for example works. Each one lists zones that every character gets a private copy of.

§templates: BTreeMap<String, Template>

Character templates by id, for example newcomer.

§abilities: BTreeMap<String, Ability>

Class abilities by id, for example soldier:suppressing-fire.

§factions: BTreeMap<String, Faction>

Factions by id, for example haulers-guild. Traffic ships name one.

§shipyards: BTreeMap<String, Shipyard>

Shipyards by id, for example exchange.

§styles: BTreeMap<String, ShipStyle>

Hull styles by id, for example merchant. Each one has a look that its ships share.

§names: BTreeMap<String, Style>

Name styles by id, for example spacer. Each one holds sample names that the Markov chain in lh_names learns from.

§phrases: BTreeMap<String, Phrase>

Phrases by id, for example human:full. A phrase joins chains and fixed text into one line, such as a full name or a gun model.

impl Content

pub fn deck_plan( &self, ship: &Ship, exits: impl Fn(&str) -> Vec<(Exit, DoorState)>, ) -> DeckPlan

The deck plan of ship, with the exits that exits gives for each room, as (exit, current door state) pairs.

Every room is marked visited, the viewer stands in the cockpit and nobody is aboard. The engine changes those three for a real viewer.

Rust note: impl Fn(&str) -> Vec<...> takes any closure with that shape, so each caller decides where exits come from.

pub fn yard_plan(&self, ship: &Ship) -> DeckPlan

The deck plan of ship from the files alone, as if it sat docked: each room’s own exits, and an open way out of the airlock.

Writes one record file under dir. When the record does not exist in this content, the file is removed instead, with any folders it leaves empty.

Every job, sorted by board number.

pub fn room(&self, id: &str) -> Option<&Room>

The room record for a room id. A copy id such as works:bay@ash-7 finds the record of its base room works:bay.

pub fn group_of(&self, room: &str) -> Option<&str>

The instance group that a base room belongs to: an instance record that lists the room’s zone, or an owned ship template that lists the room. None for a shared room.

pub fn rooms_of_group(&self, group: &str) -> Vec<String>

The base room ids of an instance group or of an owned ship template, in id order. Empty for an unknown group.

pub fn ship(&self, id: &str) -> Option<Ship>

The ship record for a ship id. An owned copy id such as lifeboat@ash-7 returns the template with every room id suffixed by @ash-7, so callers see the rooms of that copy. docked_at is left as it is.

Rust note: the result is an owned Ship and not a reference, because a copy does not exist in the map and has to be built.

pub fn area_label(&self, room: &str) -> String

Plain-English area label for a room, for example “Spindle Station · Deck 3”.
