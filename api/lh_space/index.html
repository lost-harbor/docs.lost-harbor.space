Crate lh_space 

Expand description

Space math for Lost Harbor: orbit positions, transfer arcs, and flight profiles.

The engine (lh_engine) and the web client (lh_client) both use this crate. The server simulates flights with it, and the client draws the same flights with it. Both sides call the same functions with the same inputs, so the chart on screen matches the simulation without a position stream.

The crate is pure. It reads no clock, starts no threads, and does no I/O. Every function takes the system time t as an argument. That keeps the crate deterministic and lets it build for wasm32-unknown-unknown.

§Model

  • A place has an Orbit: a parent place, a radius, a period, and a phase. place_position walks the parent chain and adds up the offsets.
  • A flight is a Course: a quadratic Bézier curve from a fixed start point, through a control point, to the target place at the arrival time. plan_course builds one. course_position gives the ship position at any time.
  • A Drive holds the acceleration and the cruise speed of a ship, after the fuel grade multiplier. flight_profile turns a path length and a drive into a flight time with burn, coast, and brake phases.

§Units

Positions are in chart units (cu). Times are in system seconds. Speeds are in cu per system second, and accelerations in cu per system second squared. The angle of an orbit grows clockwise on screen, because screen +y points down.
