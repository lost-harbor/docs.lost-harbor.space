Function plan_course 

pub fn plan_course(
    from: Point,
    target_id: &str,
    places: &[PlaceView],
    depart_t: f64,
    drive: Drive,
) -> Course
Expand description

Plans a flight from the point from to the place target_id.

The ship departs at system time depart_t with the performance drive. The function solves for the arrival time with FIXED_POINT_ROUNDS rounds of fixed-point iteration:

  1. Guess the target position at the departure time.
  2. Build the arc to that position and measure its length.
  3. Turn the length into a flight time with flight_profile.
  4. Move the target to its position at the new arrival time, and repeat.

§Returns

The planned Course. If target_id names no place, the course has zero length and ends where it starts, at depart_t.
