Module ship_mesh 

Expand description

Shared faceted hull surfaces and equipment footprints. Hull surfaces shared by orthographic drawings and the Lab volume viewer.

The Builder uses the finished plan footprint and pressure-body profile. Room boxes constrain bevels. Equipment retains its generated footprint.

Functions§

build
Builds surfaces without inventing a second silhouette for the viewer.
cross_section
Builds the outline of one cross-section from the inset of each wall at each sampling row. The points run down the right wall from the roof to the keel, then back up the left wall.
front_facets
Projects the forward-facing surfaces from the stern toward the bow.
profile_facets
Inserts starboard-facing surface projections behind windows and working fittings. The side view looks from starboard, so the bow is on the right and the faces nearest the viewer have the largest x.
to_plan
Converts a common ship point to the top drawing.
to_world
Converts drawing points back to the common ship coordinate system.
