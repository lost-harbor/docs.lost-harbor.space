Module portrait 

Expand description

Character faces: the picture, the picker grid, and the picker window. Character faces on the client: the Portrait picture, the FacePicker grid, and the face picker window.

A face is one 64-bit seed. The lh_portrait crate turns a seed into a small SVG string, the same on every machine. The client never stores a picture. It draws the face again from the seed each time.

The picker shows ten fresh seeds at a time. “Ten more” rolls ten new ones. At creation the faces come from the Works family only, with a light lean toward the chosen class. The window lets a player look at every family, and “Use this face” sends the typed command portrait set <code>, so the server checks the free change the same way for typing and clicking.
