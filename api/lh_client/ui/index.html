Module ui 

Expand description

The Leptos components that make up the screen. UI components. Layout principle: the header is the character and player. The ribbon and left column (one L-shaped panel) are the physical world. The right column is the social world. The transcript sits inside the L.

Each mod line below loads one file of components:

  • header: the top bar and the status bar.
  • world: the ribbon, the room, and the map column.
  • centre: the transcript and command line.
  • social: the right column with comms, the job, and the crew.
  • login: the connecting, login, and character screens.
  • overlays: popovers drawn over the game, such as the verb menu.
  • wm and windows: the window manager and the list of window kinds.
  • character, settings, ship, chart: bodies of windows and cards.
  • map and builder: the room map, and the content browser and editors.
