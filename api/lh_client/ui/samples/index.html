Sample room layouts per hull class, for the ship lab and the tests. Sample room layouts for each hull class, for the ship lab and the tests.

The schematic and the side view are drawn from the rooms of a ship. To see how a hull style handles a class, the lab needs many room layouts per class: compact, long, multi-level and bilateral docking layouts. Content versions add dozens of rooms to the world. So this module builds each layout as a DeckPlan straight from a few lines of text.

A layout is one picture per level, top level first. Each picture is a list of rows from bow to stern, split by /. Each letter is one room, and . is an empty cell:

Each row is centred on the middle line, so QG puts the quarters left of the middle and the galley on it. Rooms that touch on the grid get a door between them, and rooms in the same cell of two levels get a ladder. Every crew lock and freight vestibule gets a real exterior exit. A hangar or a docking collar opens through its face with no exit, since small craft and not crew use it.

Design pattern: Builder. A short text recipe becomes a full plan.

Functions§

plan
Builds the deck plan of a sample. title names the plan. The plan has no shape settings and no style. The caller adds them.
plan_levels
Builds the deck plan of any layout in the sample letters: one picture per level, top level first. The ship lab’s random layouts use it.
samples
Compact, multi-level and docking layouts for each hull class. An unknown class gets the courier layouts.
