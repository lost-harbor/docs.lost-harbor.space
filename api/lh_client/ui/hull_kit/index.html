Module hull_kit 

Expand description

The kit of hull parts that shapes every hull. Documented in its own file. Public so the ship lab can name the parts it picked. The hull kit: a hull built from parts that are known to look right.

The generator does not try to draw any hull for any room plan. It works in four steps instead:

  1. Room cubes. Each room is a box in ship space, from its size and its place in the plan (RoomVolume). A box is a strong suggestion, not a hard wall. The suggestion grows stronger toward the middle of the box. core_limit limits how deep the hull can cut into a box.
  2. Rough shell. The hull sections of the shared geometry wrap the boxes row by row (HullSection). They give a rough body with hard steps between rows.
  3. Parts. Each kit holds a short list of bows, tails and joins. The generator tries every part of the kit on the rough shell and scores it: how much room core the part cuts, how well it suits the prow setting, and its place in the kit list. A part that cuts a room core is thrown out. The best part that is left wins.
  4. Rings. The winners become one list of rings from bow to stern. Each ring is a cross-section of the hull. The top view, the side view, the front view and the volume all read these same rings, so a bow looks the same from every side.

Design patterns: the part tables are a Flyweight, because every ship shares the same static parts. The kit list is a Strategy, because each design feel picks its own parts and the matcher does not care which. The matcher is a Chain of Responsibility in spirit: each candidate in turn gets a chance, and the first good one at the lowest cost wins.
