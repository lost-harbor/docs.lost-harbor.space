Trait Transport 

pub trait Transport {

Expand description

Shared interface for both transports.

A trait is like an interface in other languages. Each transport implements these three methods, so callers can hold any of them in a Box<dyn Transport>.

Required Methods§

fn send(&self, msg: &ClientMsg)

Sends one client message to the game.

Closes the connection.

Human label, e.g. “WebSocket”.
