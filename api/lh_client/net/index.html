Module net 

Expand description

Transport layer: connects to the server over a WebSocket or a Worker. Transports. The transport layer moves messages between the UI and the game.

Both transports use the same JSON messages from lh_protocol:

  • WsTransport talks to the native server over a WebSocket.
  • WorkerTransport runs the engine in a Web Worker, inside the browser.

The rest of the client does not care which one is active. It calls send and receives ServerMsg values through callbacks. connect picks the transport at startup.
