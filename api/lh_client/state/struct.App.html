Expand description

All client state in one place.

App is Copy. Copying it only copies handles to the signals, not the data. Every component can hold its own copy and read the same state.

impl App

pub fn new() -> App

Builds the starting state. It reads saved settings and the saved user name.

pub fn plain(&self) -> bool

True when the player picked colour-off. with reads the value without copying it.

pub fn save_settings(&self)

Writes the current settings to localStorage. get_untracked reads the value without making the caller re-run on change.

pub fn my_name(&self) -> Option<String>

The name of the character being played, if any.

pub fn login(&self, user: &str)

Signs in with user. The client saves the name and asks for the character list.

pub fn take_template(&self, template: &str, name: &str)

Asks the server for a new character named name, made from the showcase template template. The server plays it at once, so the name is saved like a played character.

pub fn play(&self, character: &str)

Picks a character to play. The server answers with Welcome.

pub fn command(&self, line: &str)

Sends a typed command line and opens its transcript group. Trims the line and skips empty input. Keeps the last 200 entries of history.

pub fn map_level(&self) -> i32

The level the room map shows, relative to the current room. 0 is the level of the current room, and 1 is one level up. The map card and the map window share it. A move to another room brings the view back to 0, because the stored level belongs to the room it was chosen in. This needs no effect, so it never lags behind the map.

pub fn set_map_level(&self, level: i32)

Shows level on the room map, for the current room.

pub fn note(&self, echo: &str, text: &str)

Adds a transcript group for a local command: the typed line and one system line in reply.

pub fn note_kind(&self, kind: LineKind, text: &str)

Adds one local line of kind to the transcript, with no typed line.

pub fn run(&self, cmd: &str)

Runs a verb or link command. A command that ends in a space needs more text, so it goes into the command line instead of running at once.

pub fn stop(&self)

Stops the current action.

pub fn build(&self, op: BuildOp)

Sends a builder operation to the server.

pub fn switch_character(&self)

Leaves the current character and shows the character list. It closes the connection, so the server saves the character and takes it out of the world, then reloads the page. A session flag tells the reloaded page to skip the sign-in step.

pub fn log_off(&self)

Logs off. Sets a session flag so the next load does not sign in again, then closes the connection and reloads the page.

pub fn handle(&self, msg: ServerMsg)

The central function for incoming messages.

match checks every ServerMsg variant. Each arm writes to the signals that the matching view reads. Leptos then redraws only those views. set replaces a value. update changes it in place, as with a Vec.

pub fn push_output(&self, exec: Option<ExecId>, lines: Vec<Line>)

Adds server output to the transcript group for exec. Groups by the submit number in exec. Output with no exec joins the last group that has no command. Tells also get pinned.

pub fn open_entity(&self, kind: EntityRef, id: &str, x: f64, y: f64)

Opens the verb menu for an entity referenced by id (or name). Looks in the room first, then the character sheet. Otherwise it offers only look.
