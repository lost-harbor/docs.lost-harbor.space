lh_client

Module state 

Expand description

Client state: signals that hold everything the UI shows. Client state: one App of signals, updated by handle(ServerMsg).

The data flow is one direction:

  1. net decodes a JSON message into a ServerMsg.
  2. App::handle matches the message and sets the matching signal.
  3. Leptos re-runs only the views that read that signal.

Signals hold the state. Views read signals. Commands go out through net::send.
