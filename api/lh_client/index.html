Crate lh_client 

Expand description

Lost Harbor web client.

This crate compiles to WebAssembly and runs in the browser. It uses Leptos, a Rust UI library that renders in client-side mode (CSR). The client talks to the game with messages defined in lh_protocol. It reaches the game through either a WebSocket (native server) or a Web Worker (in-browser single player). See net for the transport and state for how messages update the UI.
