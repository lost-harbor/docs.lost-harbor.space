Crate lh_server 

Expand description

The native Lost Harbor host. It runs the same game engine as lh_worker, which runs in the browser. Here, one Engine lives behind a mutex. A ticker advances it every 100 ms and sends its output to each WebSocket connection. A watcher reloads game/content/ when those files change.

Builder edits arrive from the engine as records of kind content. When the host has a content folder, it writes them as RON files there, one file per record, so the files stay the source of truth. Other records go to the store.

Teaching note: a Mutex lets only one task touch the engine at a time. Every task takes the lock, does its work, and lets it go.

Functions§

newest_mtime
Returns the newest modification time of any file or folder under dir. Folder times count because removing a file changes only its folder. Returns None if any folder cannot be read. The watcher treats that as a change.
router
Builds the HTTP router. /ws upgrades to WebSocket, /api/info returns JSON, /api/lab/... serves the name lab (see lab), and every other path serves files from web.
serve
Runs the server until Ctrl+C. Prints the address it listens on.
start
Builds the host and starts its background tasks. Returns the shared host and the router, so tests can serve on an ephemeral port.
