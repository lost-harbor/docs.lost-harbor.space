Struct Host 

pub struct Host { /* private fields */ }
Expand description

Everything behind the lock: the engine, storage and live connections.

Teaching note: Box<dyn Store + Send> holds any storage type that can move between threads. The host does not need to know which one it has.

impl Host

pub fn lab_names(&self) -> Value

Every chain and phrase as the files hold them, with the save state.

pub fn save_phrase( &mut self, id: &str, phrase: Phrase, ) -> Result<Value, LabError>

Saves one phrase and imports the corpus lists it reaches.

Returns the file path and the ids of the imported chains. Nothing is written when the phrase has a problem.

pub fn delete_phrase(&mut self, id: &str) -> Result<Value, LabError>

Deletes one phrase file, unless a record still names the phrase.

§

impl Host

pub fn new( content: Content, store: Box<dyn Store + Send>, storage: &str, ) -> Host

Builds a host from content and storage. Loads saved records first. storage is a short label for the status line, such as memory.

pub fn engine_mut(&mut self) -> &mut Engine

The engine, for tests and tools that drive it without a socket.

pub fn set_content_dir(&mut self, dir: PathBuf)

Writes builder edits to dir from now on, as one RON file per record. It also writes any edits that were loaded from the store, so the files catch up with them.

pub fn set_lab(&mut self, lab: LabConfig)

Sets what the name lab routes may do.

pub fn flush(&mut self)

Sends pending output to every connection and persists dirty records. Send errors are ignored. A closed channel means that connection is already gone.

pub fn content_changed(&mut self, now: Option<SystemTime>) -> bool

Records a new file time for the content folder. Returns true when the time differs from the last one known, which means someone else changed the files.

pub fn tick(&mut self)

Advances the engine to the current time, then flushes its output.

pub fn reload(&mut self, content: Content)

Swaps in new content without a restart, then flushes any output it caused.
